# FreeStream TV Guide

A responsive, static directory website for the Android TV streaming-app collection supplied in the brief.

## Run locally
Open `index.html` in a modern browser. No build tools, backend, API key, or dependencies are required.

## Publish
Upload `index.html` (or this whole folder) to any static host such as GitHub Pages, Netlify, or Cloudflare Pages.

## Notes
- App names, regions, and versions reflect the supplied source list and may be outdated.
- Google Play links are official listing URLs generated from the package IDs in the supplied list.
- Availability, device compatibility, free tiers, and catalogues vary by country and can change.
- The site does not host APK files or stream copyrighted content.
