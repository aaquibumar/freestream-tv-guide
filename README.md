# FreeStream TV Guide

A responsive, searchable directory of streaming apps and useful utilities for Android TV and Google TV.

**Live website:** https://aaquibumar.github.io/freestream-tv-guide/

## Features

- Search the app directory by name, region, or package ID.
- Filter listings by region and sort alphabetically.
- Responsive layout for desktop and mobile screens.
- Branded SVG favicon and browser theme color.
- Search-engine metadata, canonical URL, Open Graph metadata, structured website data, robots.txt, and XML sitemap.
- About section explaining the directory's scope and limitations.

## Run locally

Open `index.html` in a modern browser. No build tools, backend, API key, or dependencies are required.

## Publish

The site is hosted with GitHub Pages from the `main` branch and repository root.

## Important notes

- App names, regions, and listed versions reflect the supplied source collection and may be outdated.
- Confirm availability, compatibility, pricing, and current versions on each official listing before installing.
- Region restrictions and catalogues vary by service and country.
- This site is an independent directory. It does not host APK files or stream copyrighted content.
- App names and trademarks belong to their respective owners.
